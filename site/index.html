How it works

Screenshot tools stop at the image.

Snipflag keeps going until the Linear issue exists. One shortcut replaces the whole routine.

The usual way

  1. Screenshot
  2. Paste into an editor
  3. Draw a box
  4. Save the file
  5. Open Linear
  6. New issue
  7. Drag the file in
  8. Pick project and assignee
  9. Describe the picture

Then again for the next screenshot.

With Snipflag

  1. Snip it. Press Ctrl Shift 2 and drag over anything on screen, in any app.
  2. Mark it up. Arrows, boxes, numbered steps and text. Pixelate anything private.
  3. Send it to Linear. Pick team, project, labels and priority, then Create issue. Add more screenshots first if you need them.

One Linear issue, every screenshot in order.

Features

Small app. Complete Linear issue.

Works outside the browser

Capture any app on any monitor: desktop apps, design tools, terminals, the browser. No extension needed.

Linear fields in the app

Team, project, assignee, labels, priority and description templates. It remembers what you used for each team.

Many screenshots, one issue

Up to 10 per issue, each with its own marks and undo history. Reorder, caption, and mention them with @image.

Pixelate before you send

Real block pixelation burned into the pixels, not a layer someone can peel off.

Never lose a draft

Drafts save as you work and come back after a restart.

No duplicate issues

If the network drops, a retry checks Linear first instead of filing a second issue.

Local-first

Your screenshots stay on your computer until you click Create issue.

Then they go straight to Linear. There is no Snipflag server, no account and no analytics, and the code is open for anyone to check.

FAQ

Questions.

How is this different from ShareX or Snagit?

ShareX and Snagit are great screenshot tools. They give you an image, and filing the issue is still up to you. Snipflag is built for that last step: you pick the team, project, labels and priority in the app and create the Linear issue with every screenshot in order. Snipflag vs ShareX, Greenshot and Flameshot

Who is Snipflag for?

People who work in Linear every day and report visual bugs themselves: developers, designers, founders and small product teams. If you need session recordings, console logs or a feedback widget for customers, Jam or BugShot fits better.

Is Snipflag free?

Yes. It's free and open source under the MIT License. No account, subscription or screenshot cloud.

How does Snipflag connect to Linear?

Choose Connect Linear, approve access in your browser, and go back to Snipflag. It uses Linear OAuth with PKCE, keeps the token in your system's credential store, and never uses a client secret. Details

Why does my computer warn about the installer?

v1.2.0 is an unsigned preview. Installers are built on GitHub Actions with published checksums, but they are not code-signed yet.

Does it record video or console logs?

No, Snipflag is screenshots only. For recordings or browser logs, Jam or BugShot is a better fit.

Does it work with Jira or GitHub Issues?

No, and that's on purpose. Snipflag is built only for Linear so it can follow Linear's fields and workflow closely. You can still copy or save any annotated screenshot as a PNG.
