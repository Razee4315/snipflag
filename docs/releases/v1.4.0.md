Snipflag 1.4.0 makes the everyday flow harder to break: Undo covers more, nothing is sent or edited behind your back, being offline is no longer mistaken for being signed out, and text marks stay readable on busy screenshots.

**This release is for Windows.** macOS and Linux stay on [1.3.0](https://github.com/Razee4315/snipflag/releases/tag/v1.3.0) for now.

## New

- **Undo covers more:** Ctrl+Z (and the Undo button) puts back a removed screenshot, a crop or a reorder when that was the last thing you did.
- **Text that reads on anything:** turn on "Background behind text" in the text options for a plate behind the letters. Snipflag remembers your last color, width, text size and this choice.
- **Progress you can see:** a progress bar while a report is prepared, uploaded and created, and the download percent while an update installs.
- **Keyboard:** with the Select tool, Tab on the screenshot steps through your marks. Colors, widths and the Settings sections are a single Tab stop each, moved with the arrow keys. The focus ring now shows in Windows high contrast.
- Up to three messages stack at the bottom of the window, and a message stays while the pointer is on it, so an Undo is never lost while you reach for it.

## Improved

- **Offline:** if Linear can't be reached, the issue panel says so and offers Retry instead of asking you to connect again.
- **Sending:** screenshots upload three at a time; team projects, members and labels load together; choosing a team and pressing Ctrl+Enter at once no longer fails with "another operation is in progress". If Linear refuses an issue (for example a label that was removed), you see why and can fix it straight away; the report is no longer locked for a separate check.
- **Nothing happens unseen:** Ctrl+Enter opens a hidden issue panel instead of sending from it; keys pressed in a dialog no longer change the screenshot behind it; the capture shortcut brings Snipflag forward to say why when a session is full or locked.
- **Drafts:** Snipflag reopens the session you had open last, and only if it hasn't been sent. A new screenshot is saved at once. Starting a new session tells you the old draft is in History, and emptied drafts are removed instead of listed.
- **Settings** asks before closing with unsaved changes, keeps your other preferences if one stored value is invalid, and keeps remembered teams cleared after Disconnect.
- Lines, arrows and pen strokes are selected by clicking the stroke itself, so a long arrow no longer blocks the marks around it.
- Copy for AI reuses the saved file of a screenshot you haven't changed; Copy image and Save image show that they are working.
- Settings, History and the report preview load when first opened, so the editor starts lighter.

## Downloads

Windows x64: `.exe` (recommended) or `.msi`. `SHA256SUMS.txt` lists checksums and `latest.json` is used by the updater: Windows installs of 1.2.0 and 1.3.0 can update in place from the Update button in the title bar. On macOS and Linux, 1.3.0 remains current and the in-app update check finds nothing to install.

**Unsigned installers:** Windows code signing isn't configured, so SmartScreen will ask before opening the app. The update package carries Snipflag's own update signature, which the app checks before installing.

**What has been checked:** automated checks (build, 64 unit tests, 33 browser tests, 38 native tests, clippy) and packaging passed on Windows. This build has not yet been tried by hand in the installed app, and an in-place update has not been exercised.
