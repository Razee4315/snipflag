Snipflag 1.2.0: see exactly what you are about to send, start reports from templates, connect Linear in one click, and get future versions automatically.

## New

- **Report preview:** the eye button next to Create issue shows the outgoing issue before anything is uploaded: team and workspace, priority, project, assignee, labels, title, description with image references, and every screenshot in order with its annotations and pixelation burned in. You can also see the exact Markdown Linear will receive.
- **Templates:** Bug report, Visual defect, Regression and Design feedback appear under an empty description. Edit, add or remove them in Settings → Templates. A template never replaces text you already wrote.
- **Remembered issue details:** after an issue is created, its project, assignee, labels and priority are remembered for that team and fill in empty fields next time. Settings can forget them.
- **Automatic updates:** Snipflag checks for signed updates and shows an Update button in the title bar. It saves your draft before installing, and you can turn checking off in Settings → About. This is the first version with the updater, so install it manually once; later versions can update in place.
- **One-click Linear connection:** choose Connect Linear and approve in your browser. A custom OAuth application is still available under Advanced.

## Improved

- Your last team is also selected for new sessions, not only at startup.
- Long team, project and member lists have a search field, and failed team details can be retried.
- Drafts are more durable: emptied drafts stay empty, Quit waits for the latest save, undo history survives restart, failed deletions stay visible and retryable.
- Uncertain submissions are locked to the exact report that was sent and are checked with Linear before anything is sent again.
- Filmstrip and mention thumbnails show the protected, pixelated version of each screenshot, and pixelation now replaces the covered pixels completely.

## Downloads

Windows x64 offers `.exe` and `.msi`, macOS offers Apple silicon and Intel `.dmg` files, and Linux x64 offers `.deb` and `.AppImage`. `SHA256SUMS.txt` lists checksums, and `latest.json` is used by the updater.

**Unsigned installers:** Windows and macOS code signing and notarization are not configured, so SmartScreen and Gatekeeper will ask before opening the app. Update packages carry Snipflag's own update signature, which the app verifies before installing. Automated checks and packaging passed on all platforms; native runtime checks, including a real update from this version to the next, are still being completed.
