# Name decision — 2026-09-26

Chosen: **Snipflag**. Snip a screenshot, flag the problem. Tagline: **Snip it. Mark it. Flag it.** Repository: `Razee4315/snipflag` (private during development; renamed from `nacrelark` on 2026-09-26, history preserved, GitHub redirects the old URL). Bundle identifier: `io.github.razee4315.snipflag`.

The owner asked for a name that reads like a software product instead of the invented word Nacrelark, and asked for Google and GitHub checks.

## Evidence for Snipflag

- GitHub `GET /search/repositories?q=snipflag`: total_count = 0. `GET /users/snipflag`: 404 (no user or organization).
- Exact web search `"Snipflag"`: no product, company, or project by that name. Results were only the generic words (snip, sniper flags).
- Google search for `Snipflag`, checked directly in a browser: no "did you mean" rewrite to another brand. Results were generic Windows Snipping Tool pages and screenshot tools, which is the product category and not a name collision. Google's own "people also search for" suggestions were `Snipflag download` / `Snipflag app`, which means there is no existing entity the query gets pulled toward.

## Candidates rejected in the same check

- Nacrelark (previous name): no collision, but hard to spell and pronounce, and it doesn't say what the app does.
- Shotkite: 0 GitHub repos, but web search is pulled to **Shotkit**, a large photography brand. That is the same autocorrect trap that ruled out Clipsenda (ClipSend).
- Framekite / Pixkite: pulled toward FrameKit apps, and Pixkite has existing social accounts.
- Shotfile, Framefile, Snapfile, Markfile, Clearshot, Lumark, Snipline, Pinshot, Shotmark, Snaptrail, Capturo, IssueLens, Evidex: existing GitHub repos or products with the same name.
- Shotflare and Tellframe: clean, but Shotflare reads as a Cloudflare derivative and Tellframe does not describe the product.
- Earlier rounds: Clipsenda (Google corrects to ClipSend, clipsend.io), SnipRelay (sniprelay.com), Markvio (App Store product), Quivmark, Mivroquill, Ternshot, Fletchframe, Pixelmarten.

This is a dated collision screen. It does not guarantee exclusivity, domain availability, trademark clearance, or SEO ranking. No domains or handles have been bought or reserved. Repeat the checks before a public launch.

SEO direction: pair the brand with descriptive copy, e.g. "Snipflag — screenshot annotations for Linear", and mention Windows, macOS, Linux, and multiple screenshots in one issue. Don't keyword-stuff the product name.
